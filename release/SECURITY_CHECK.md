# Security check — MarkDown Ultimate release artifacts

**Author:** AlexRabbit  
**Purpose:** Record what was reviewed before GitHub Release upload. This is not a guarantee of zero risk.

## Scope

- Folder: `release/artifacts/` (generated by `QTestings/prepare-release.ps1`)
- Assets: `MarkDownUltimate.exe`, `MarkDownUltimate-Portable.zip`, `MarkDown-Ultimate.apk`

## Excluded from git (by design)

| Item | Reason |
| --- | --- |
| `aimemos/`, `.cursor/` | Private dev notes |
| `target/`, `.trunk-target/` | Build caches |
| `**/logs/hot/*.jsonl` | Runtime telemetry |
| `.env` | Local secrets — use `.env.example` only |
| `release/artifacts/` | Binary staging (gitignored) |

## Pre-upload commands

```powershell
.\QTestings\scan-release-secrets.ps1
cargo audit
```

## Portable bundle contents

- Embeddable Python from python.org (verify checksum when upgrading version in `tools/portable-bundle.ps1`)
- Built static `dist/` (WASM + JS)
- `MarkDown-Ultimate-Portable.exe` (Rust launcher, no network calls)
